# Skin Cancer Detection Using TensorFlow

## Overview

This project uses TensorFlow and EfficientNet to classify skin lesion images into 9 categories from the ISIC skin cancer dataset.

## Classes

* Actinic Keratosis
* Basal Cell Carcinoma
* Dermatofibroma
* Melanoma
* Nevus
* Pigmented Benign Keratosis
* Seborrheic Keratosis
* Squamous Cell Carcinoma
* Vascular Lesion

## Technologies Used

* Python
* TensorFlow
* Keras
* EfficientNet

## Features

* Model training on ISIC dataset
* Image classification
* Prediction confidence score
* Saved trained model for reuse

## How to Run

```bash
python train.py
python predict.py
```
